# WinRAR/7z/ZIP Password List Cracker

This tool is a fixed and enhanced version of the original password cracker script from [EbolaMan-YT/WinRAR-Cracker](https://github.com/EbolaMan-YT/WinRAR-Cracker). It is a Windows batch file script designed to crack passwords for WinRAR, 7z, or ZIP files using a password list.

## 📋 Features

- Supports WinRAR, 7z, and ZIP file formats.
- Uses a password list to find the correct password.
- Fixes issues with the password handling process in the original script.
- Simple and easy-to-use interface.

## 🚀 How It Works

1. **Run the Script**:
   - Open the `zipwn.bat` file.

2. **Input Required Information**:
   - The script will prompt you to provide:
     - The file path of the compressed file.
     - The file path of the password list document.

3. **Crack the Password**:
   - The script will iterate through the passwords in the list and attempt to unlock the compressed file.
   - If the correct password is found, it will display it.

## 📦 Requirements

- A Windows operating system.
- WinRAR or 7z installed on the system.
- A password list document (e.g., `.txt` file) containing possible passwords.

## 📝 Example Usage

1. Double-click on the `zipwn.bat` file to open the script.
2. Follow the prompts to:
   - Provide the path to the compressed file.
   - Provide the path to the password list.
3. Wait for the script to process and display the correct password if it is in the list.
