# Face Recognition Tool

This tool is designed to help users sort out images containing faces using the `face_recognition` Python package. It identifies images with faces and moves them to a separate folder for further processing or organization.

## 📋 Features

- Detects images containing faces.
- Moves images with detected faces into a designated folder (`not_sorted`).

## 🚀 How It Works

1. **Prepare Your Images**:
   - Place all the images you want to process into the `raw_images` folder.

2. **Run the Tool**:
   - Execute the `main.py` file:
     ```bash
     python main.py
     ```

3. **View the Results**:
   - The tool will scan the images in the `raw_images` folder.
   - Images containing faces will be moved to the `not_sorted` folder.

## 📦 Requirements

- Python 3.x
- Required Python package:
  ```bash
  pip install face_recognition
  ```

## 📝 Example Usage

1. Place your images into the `raw_images` folder.
2. Run the `main.py` script:
   ```bash
   python main.py
   ```
3. Navigate to the `not_sorted` folder to view images containing faces.
